## � **Project Overview**

ORBITNET-MESH is an innovative satellite communication relay system that eliminates data loss during communication blackouts through intelligent store-and-forward mesh networking. Built to solve the space industry's most critical challenge: ensuring mission-critical data reaches Earth safely.

### **🎯 The $2.4B Problem**
- **$2.4 billion** lost annually due to satellite communication failures
- **45% data loss** during communication blackouts (industry average)
- **$50+ million** cost per failed mission (Luna-25, NASA missions)
- **Growing complexity** with mega-constellations (Starlink, OneWeb)

### **💡 Our Revolutionary Solution**
- **Zero data loss** through intelligent buffering
- **Mesh networking** between satellites for redundant paths
- **Real-time AI decision making** with smart link selection
- **Mission control grade** interface for operators

## 🚀 **Quick Start**

### **Prerequisites**
```bash
Node.js 18+ and npm
Python 3.11+
Git
```

### **Installation & Launch**

```bash
# Clone and setup
git clone <repository-url>
cd orbitnet-mesh
npm install
cd backend && pip install -r requirements.txt && cd ..

# Launch system (2 terminals)
python backend/main.py     # Terminal 1: Backend
npm run dev               # Terminal 2: Frontend
```

### **🎮 Experience the Demo**
1. **Open**: http://localhost:5173
2. **Start Mission**: Click the big red button
3. **Watch Magic**: Real payload files flowing through system
4. **See Protection**: ORBITNET prevents data loss during blackouts
5. **Witness Recovery**: Buffered data flushes when link restored
